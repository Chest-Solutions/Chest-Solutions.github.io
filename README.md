# Dark

The Dark website — free and open-source Minecraft mods and plugins.

Built with React, Vite, Tailwind CSS, Framer Motion, and lucide-react.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build outputs to `dist/` and is deployed to GitHub Pages via
`.github/workflows/deploy.yml`.
